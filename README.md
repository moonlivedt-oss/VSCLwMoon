# VS Code Launcher — переключатель нагрузки

Открывает VS Code только с нужными в этой сессии стеками расширений. Остальные
тяжёлые языковые серверы (Java/redhat, SonarLint ~880 МБ, cpptools, 15 Azure и
т.д.) **не грузятся** → экономия ~1–1.5 ГБ ОЗУ.

## Как работает
Ничего не удаляется и не правится в базе VS Code. Просто запуск с флагами
`--disable-extension <id>` для всех расширений из **невыбранных** категорий.
Обычный запуск VS Code (не через лаунчер) — снова со всем набором.

Работает и со стабильной сборкой, и с **VS Code Insiders** (определяется
автоматически; для Insiders корректно закрывается `Code - Insiders.exe`).
Оценка «~N МБ экономии» считается только по **реально установленным**
расширениям выключаемых стеков.

## Запуск
- Двойной клик по **`Запустить.bat`** (рекомендуется — детач от терминала).
- Или: `pythonw vscode_launcher.py`

> ⚠️ Если включена галочка «Закрыть запущенный VS Code», **не** запускай тул из
> встроенного терминала VS Code — он закроется вместе с редактором. Используй
> `Запустить.bat` (он стартует отдельным процессом).

## Что в окне
- **Стеки/категории** — галочки (Git, Python, C/C++, Java, Web, SQL, Azure, 3D,
  Markdown, PowerShell, SonarLint). Отмечаешь нужное на сессию. У каждого стека —
  бейдж «нагрузки» (лёгкий/средний/тяжёлый) и кнопка **«Подробнее»**: список
  плагинов стека, что каждый делает и установлен ли он. Прямо из диалога можно
  **управлять расширениями**:
  - **Установить** (у строки со статусом «нет в системе») или **Установить
    недостающие** сразу для всех — тянет из маркетплейса (`code --install-extension`);
  - **Удалить** (красная, у установленных) — `code --uninstall-extension`;
  - обе операции идут в фоне и **спрашивают подтверждение** («Скачать и
    установить?» / «Удалить расширение?», по умолчанию — «Нет»);
  - после операции статус строки, кнопки и счётчики на карточке обновляются сами.
- **Ядро (🔒)** — косметика, Claude, продуктивность, орфография, русский язык —
  грузятся всегда (лёгкие). Git-инструменты вынесены в отдельный стек **Git**,
  потому что GitLens заметно ест память — на не-git проектах его удобно отключать.
- **Пресеты** — сохрани набор («Python», «Веб», «Всё») и переключайся одним кликом.
  Кнопки **⭱ / ⭳** экспортируют/импортируют пресеты в JSON (перенос между машинами;
  импорт объединяется с текущими).
- **Живой замер памяти** (сверху) — «VS Code сейчас: N МБ · M проц.»: реальный
  working set всех процессов `Code.exe` (не оценка). Кнопка **⟳** обновляет; после
  запуска замер сам обновляется через несколько секунд — видно фактический эффект.
- **Папка** — какой проект открыть (необязательно) + недавние.
- **Закрыть VS Code перед стартом** — чтобы память реально освободилась (иначе
  старые окна продолжат держать свои расширения). Сохрани файлы заранее!
- **Без GPU-ускорения** (`--disable-gpu`) — для слабых/глючных видеокарт.
- **Голый режим** (`--disable-extensions`) — отключает вообще все расширения,
  включая ядро. Максимальная скорость; галочки стеков при этом игнорируются.
- **Профиль** — открыть окно с конкретным профилем VS Code (`--profile <имя>`).
  Профиль нужно **заранее создать** в VS Code (шестерёнка → Profiles) — из CLI
  наполнить профиль расширениями нельзя, поэтому тул только переключает на готовый.
- **Показать команду** — превью того, что запустится.

## Производительность самого лаунчера
Список установленных расширений читается напрямую из
`%USERPROFILE%\.vscode\extensions\extensions.json` (~1 мс) вместо запуска
`code --list-extensions` (~0.5 с со спавном Node). Список грузится в **фоновом
потоке** (окно не подмерзает) и **кэшируется** в `launcher_config.json`, поэтому
последующие запуски показывают стеки мгновенно. Медленный CLI остаётся
надёжным фолбэком (портативные сборки, WSL, нестандартная папка расширений).

## Категории
Карта «расширение → категория» лежит в **`categories.json`** — редактируй под себя.
Всё, чего нет в карте, считается неизвестным и **остаётся включённым** (безопасно).

## Проверка логики без GUI
```
python vscode_launcher.py --selftest python,web
```
Покажет, что будет включено/выключено и итоговую команду.

## Файлы
| Файл | Что |
|---|---|
| `vscode_launcher.py` | точка входа (запуск GUI или `--selftest`) |
| `launcher/core.py` | логика: поиск CLI, чтение/установка/удаление расширений, сборка команды, замер памяти |
| `launcher/theme.py` | палитра Catppuccin Mocha, генератор QSS, тёмный тайтлбар |
| `launcher/gui.py` | окно PyQt6 (карточки, пресеты, диалоги) |
| `categories.json` | карта расширений по категориям (правь под себя) |
| `plugin_descriptions.json` | id → «что делает» для окна «Подробнее» (собран из `../VS_code_Info/Extensions.md`; нет файла — читается тот .md напрямую) |
| `banner.png` | картинка-баннер в шапке окна (необязательна; нет файла — будет ровный фон) |
| `launcher_config.json` | пресеты, недавние папки, последний выбор, кэш расширений (создаётся сам) |
| `Запустить.bat` | запуск отдельным процессом |
