# Политика безопасности

## Как сообщить об уязвимости

Пожалуйста, **не открывайте публичный issue** для проблем безопасности. Вместо этого:

- приватный канал GitHub - вкладка **Security -> Report a vulnerability** в этом репозитории;
- либо напишите автору через профиль [@moonlivedt-oss](https://github.com/moonlivedt-oss).

Опишите, что нашли, как воспроизвести и в чём потенциальный вред. Исправления выходят в
ближайшем релизе, в CHANGELOG они отмечены отдельно.

## Модель угроз

Лаунчер - локальная программа для Windows без сервера и телеметрии. Что он делает с системой:

- **Запускает VS Code** напрямую через `Code.exe` списком аргументов, без `cmd.exe`; id
  расширений, путь к папке и имя профиля проверяются и очищаются (подробно - раздел
  «Безопасность» в [README](README.md#безопасность)).
- **Правит PATH** только через реестр (`HKCU\Environment`, для системного PATH - с UAC и по
  согласию), перед правкой пишет бэкап `path_backup_*.txt` рядом с конфигом.
- **Ставит и удаляет тулчейны** через `winget` только по id из встроенного каталога; полное
  удаление берёт папку, только если пакет числится у winget и имя папки совпадает с его id,
  системные места защищены.
- **Читает чужие файлы как недоверенные:** `extensions.json` VS Code, `settings.json` проекта,
  файл замеров Moon Core (`mooncore-perf.json`: размер, схема и числа проверяются).
- **Сеть** - `winget` при установке и проверка новой версии лаунчера через GitHub Releases API;
  ссылки на Marketplace открываются в браузере. Телеметрии нет, «Отчёт для поддержки»
  сохраняется в файл, отправляете его вы.

Особенно интересны: способ заставить лаунчер выполнить чужую команду через содержимое конфигов
или имён папок, удалить что-то вне выбранного пакета, записать PATH без подтверждения.
